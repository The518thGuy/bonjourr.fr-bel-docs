## 📄 Макет старонкі {#page-layouts}

Элементы Bonjourr можна падзяліць на адну, дзве або тры слупкі. На кожным макеце віджэты можна размясціць і выраўнаваць па-свойму, дзякуючы чаму вы можаце ствараць разнастайныя расклады і пераключацца паміж імі.

Для кожнага макета асобна захоўваюцца наступныя налады:

- актываванасць віджэта (ці ён уключаны);
- усе параметры размяшчэння на сетцы;
- скід налад.

## 📚 Шрыфты {#fonts}

Bonjourr выкарыстоўвае шрыфты з Fontsource — каталога шрыфтоў **з адкрытым зыходным кодам**. На выбар для дапасавання інтэрфэйсу новай карткі да свайго густу даюцца сотні гарнітур.

Каб праглядзець даступныя шрыфты, перайдзіце на сайт [fontsource.org](https://fontsource.org/).

[![Прагляд шрыфтоў Bonjourr на Fontsource](@assets/documentation/customisation/fontsource.png)](https://fontsource.org/)

### Але што наконт іншых шрыфтоў? {#other-custom-fonts}

Utilisez du CSS dans le champ **Style personnalisé** pour appliquer à Bonjourr [n'importe quelle police installée sur votre ordinateur](https://wordmark.it/). Par exemple :

```css
/* applique une police personnalisée à tous les widgets */
#interface {
    font-family: Comic Sans MS;
}
```

Vous pouvez même utiliser les propriétés `@import` ou `@font-face` pour importer des polices depuis une URL distante provenant de [Google Fonts](https://fonts.google.com) ou de tout autre service de polices.

```css
/* applique une police Google Fonts à tous les widgets */
@import url('https://fonts.googleapis.com/css2?family=IM+Fell+English:ital@0;1&display=swap');

#interface, #pomodoro_container {
  font-family: "IM Fell English", serif;
  font-weight: 400;
  font-style: normal;
}
```
